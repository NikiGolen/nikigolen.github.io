LAB PROTOTYPE

AI Product Discovery

Turns "something modern with cable management" into a ranked, explainable desk recommendation instead of a keyword search. Runs on the Google Gemini API via a Cloudflare Workers backend, with the intent-scoring reasoning shown alongside each result. Scoped to a single product category (desks) so the matching logic could go deep instead of wide.

Scoped to desktop for this prototype.

Problem

Traditional e-commerce search relies on rigid keyword matching, forcing customers to use exact product names rather than describing what they actually want to achieve. This often leads to poor results when complex preferences or negative constraints are applied.

This prototype explores how natural language understanding, dynamic product taxonomy, multi-attribute intent scoring, and explainable AI can transform e-commerce discovery specifically for office desks. By parsing conversational queries into weighted match percentages and transparent reasoning, the interface bridges the gap between user intent and structured catalog data.

BUILT WITH: VANILLA JS, LOCAL JSON, INTENT SCORING, CLOUDFLARE WORKERS, & GOOGLE GEMINI API
