Interactive 3D SimLab Room Builder

A Three.js application I built from scratch for planning clinical simulation spaces. It handles real-time 3D rendering, constraint-based equipment placement, wall-mounted vs. floor-standing object logic, camera-relative wall transparency, and a live bill-of-materials cart. No game engine, no framework, just vanilla JavaScript.
