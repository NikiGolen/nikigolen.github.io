# Experiments

This directory contains interactive prototypes and technical experiments that complement my portfolio website.

Each project explores a specific technical concept through a working proof of concept, with a focus on AI, ecommerce platforms, technical program management, and software engineering.

## Current Projects

### AI Product Discovery
Natural language product discovery using intent scoring, product taxonomy, explainable AI, Cloudflare Workers, and the Google Gemini API.

### Technical Program Studio
Interactive planning environment for visualizing technical programs, initiatives, roadmaps, and project execution.

### Attribute Resolution Engine
Prototype demonstrating query-time attribute resolution and taxonomy-driven schema fallback for product discovery.

### 3D Simulation Room Builder
Interactive 3D environment for designing healthcare simulation spaces and configuring room layouts.
