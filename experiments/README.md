## Experiment Descriptions
### Interactive 3D SimLab Room Builder
A browser-based workspace for designing clinical simulation environments in real-time 3D. This experiment explores procedural 3D rendering, constraint-based equipment placement, dynamic room visualization, and interactive planning workflows built entirely with Three.js and vanilla JavaScript.
* **Core Concepts:** Three.js · 3D Rendering · Spatial Constraints · Vanilla JavaScript

### AI Product Discovery Lab
An interactive prototype exploring how AI can transform ecommerce search into personalized product discovery experiences. This experiment is a simulated AI commerce environment demonstrating conversational discovery, intelligent recommendations, product comparison workflows, search optimization, and future-state digital shopping experiences.
* **Core Concepts:** AI Commerce · Product Discovery · Search Strategy · JavaScript

### Technical Program Management Studio
An interactive workspace for exploring how technical programs are planned, structured, and executed. This experiment is a simulated enterprise program management environment demonstrating technical strategy, architecture planning, cross-functional alignment, dependency management, risk mitigation, and execution tracking.
* **Core Concepts:** Technical Program Management · Architecture Planning · Risk Management · JavaScript

### Query-Time Schema Fallback (QSF)
A middleware prototype exploring resilient search by recovering missing product attributes during query execution. This experiment demonstrates how an intermediate query layer compensates for incomplete catalog schemas using runtime attribute inference, fallback resolution, and semantic filtering instead of relying solely on upstream feed validation.
* **Core Concepts:** Search Architecture · Middleware · Schema Resolution · JavaScript
